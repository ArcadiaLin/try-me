# 视频脚本

状态：已审阅用户截至「ほら！」的首轮脚本，并于 2026-11-17 补充候选建议。建议尚未经动态分镜和试听验证，全曲创意方向仍待确认。

## 总体设计

- 本段候选概念：Clawd 在同一小舞台自我介绍，用逐步出现的道具展示能力。
- 本段表演变化：招呼与等待回应 → 自信介绍 → 连续能力展示 → 一次贴地回弹作为小亮点。
- 用户原稿已有的视觉规则：道具从画外进入，尽量保持角色主体连续；没有明显画面指向的句子由待机动画承接。
- 候选补充：道具用后向原方向退场；跨句保留角色姿态、视线或道具，减少每句重新开场。全曲开场与结尾的呼应仍待设计。

## 环境动画试作：舞台前沿自动演奏键盘（橙色段）与悬浮叠层底座

2026-11-17 按用户提供的候选设计，在 `TryMeVerse1MV`（`00:00.000 → 00:55.168`）接入了**舞台前沿自动演奏键盘**试作版供审阅（第一次副歌结束后的键盘重现及侧边元素暂不接入）：

- **橙色段专属装置与进退场**：
  - **首次出现（`0.01s–0.24s`）**：舞台前侧先打开一道窄缝，横跨一个八度加三度（10 白键 + 7 黑键，键位关系正确，宽 `610px` 比 `1000px` 舞台窄、两端留出结构）的深色键盘托盘从窄缝向下滑出并略向观众展开，在第一个音符（`0.254s`）到来前落位。Clawd 站立的舞台上沿始终不动。
  - **橙色转青绿退场（`18.47s–18.95s`）**：第 4 轮最后一个音的琴键松开 → 橙色内衬与指示窗熄灭 → 键盘收平 → 整体缩回舞台遮挡范围，青绿段完全离开。
- **机械按键动作与前侧三指示窗**：
  - 围绕三个固定位置反复跳动（左低半音下切位、左基准位、右高八度位），其余琴键保持安静。
  - 每次按动以后端为支点、前端快速压下，呈现键面倾斜与前端厚度压缩，并在键槽前沿与侧壁露出橙色内衬；松开后短促回弹，橙色即刻熄灭，不留长光尾；快速交接时允许前键回弹未尽、后键已压下。
  - 键盘前侧下沿对应三个演奏键位设有三个短短的机械指示窗，仅在对应键按下时由内部连杆带动向下翻出一块橙色小面，与琴键属于同一次动作。
- **底部主次礼让**：橙色段（`0.00s–18.88s`）将键盘按动作为唯一主要的底部效果，把原来的两层悬浮底板律动幅度压低至 `22%`，并暂停最下层底板内部向两端传递的脉冲；`18.88s` 键盘收回后，两层悬浮底板与重点脉冲恢复为主舞台底部律动。

- **声画分工**：环境承担持续节奏，Clawd 保持叙事与重点动作。第一次副歌结束前，新增节奏装饰集中在舞台下方；左右画幅新增元素的出现、移动与退场留到第一次副歌结束后。此限制针对环境装饰，不改变已有叙事道具和思考气泡；具体引入时间待试听确认，不从当前候选组范围推断副歌边界。
- **造型**：舞台下方悬着两层薄底板，轮廓呼应现有舞台，越往下略窄，层间留出清楚的空隙。Clawd 接触的舞台上沿保持稳定，形变只发生在下方底板及其间距，避免角色脚滑或整座舞台反复跳动。
- **基础律动**：拍点到来时，上层底板先轻微靠近舞台，下层稍晚跟随，随后依次回落，形成短促的“收紧—释放”。回弹落位明确，避免持续漂浮；常态幅度克制，弱处减小运动但保留结构。节拍组织动作，声音强弱可作为幅度参考，具体映射与延迟待预览调整，不机械响应每个起音。
- **重点脉冲**：最下层底板内部藏一条短槽，仅在试听筛选出的重点节奏处，出现短亮块从中央向两端传递，然后消退。常态以形体运动为主，脉冲偶尔出现；不做持续填满的加载条，不叠加满屏粒子、光圈或随机频谱柱。
- **配色与主次**：沿用舞台现有颜色，以明暗区分两层底板，脉冲只用一种强调色。角色和道具表演密集时降低底座运动幅度，保证主要动作可读；是否发光、具体尺寸、幅度和回弹时长均待试看。
- **后续展开候选**：第一次副歌结束后，可尝试让一次抵达底座端点的脉冲引出画幅侧边元素，再逐步发展成左右回应。此衔接尚未确定，不先绑定任何具体候选事件。

验收重点：脚部接触稳定；底板层次在当前构图中可读；持续律动不过分抢戏；重点脉冲足够稀疏；与现有道具及角色动作互不遮挡。须配原音源试听和动态预览后再确认执行参数。
