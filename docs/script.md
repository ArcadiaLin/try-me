# 视频脚本

状态：已审阅用户截至「ほら！」的首轮脚本，并于 2026-11-17 补充候选建议。建议尚未经动态分镜和试听验证，全曲创意方向仍待确认。

## 总体设计

- 本段候选概念：Clawd 在同一小舞台自我介绍，用逐步出现的道具展示能力。
- 本段表演变化：招呼与等待回应 → 自信介绍 → 连续能力展示 → 一次贴地回弹作为小亮点。
- 用户原稿已有的视觉规则：道具从画外进入，尽量保持角色主体连续；没有明显画面指向的句子由待机动画承接。
- 候选补充：道具用后向原方向退场；跨句保留角色姿态、视线或道具，减少每句重新开场。全曲开场与结尾的呼应仍待设计。

## 键盘演奏、环境节奏弹出图标与「小 Clawd 协奏乐队」设计（2026-11-18 更新）

2. **第一段副歌结束前（方案 A：前奏由 Clawd 主体弹奏紧凑小合成器，主歌收起让位叙事）**：
   - **前奏橙色段（`00:00.254 → 00:18.477`，`SYNTH_000–SYNTH_004`）**：一台尺寸与角色/书本相仿的**紧凑 3D 像素小合成器（`KeyboardProp`）**在 `0.02s–0.24s` 从左侧滑入 Clawd 身前；复用实体前肢位移与重合描边逻辑，由 Clawd 的**左爪负责低音区（`A3` 下切与 `B♭3` 基准音）**、**右爪负责高八度（`B♭4`）**亲自按键弹奏，视线随左右手弹奏自然追随。
   - **主歌交接（`18.47s–18.88s`）**：第 4 轮末音收束、主唱开口（`L001 Hey, let's go`）瞬间，Clawd 双爪收回，小合成器向右侧轻巧滑出退场，让 Clawd 空出双手投入主歌叙事动作（挥手、钻待命槽、跳终端、看热力图、双手捧书、吹小号），互不干扰。
3. **副歌 1 与副歌后间奏的「Claude Cowork 小分身伴舞 / 代弹键盘 / 全员乐队」递进设计（已写入时间轴 `L017`、`L021`、`L023` 与 `SYNTH_013–014`，待后续段落制作时实现）**：
   - **`L017`（`01:07.495 → 01:11.613`，*"I'm quick to learn and I can work with people in a team"*）**：结合 Claude 的 **Cowork / 多智能体人机协作**能力，画面直接产出几个**小型 Clawd 分身**以及代表真实人类的协作符号，表现 `team` 人机协同；随后小 Clawd 分身留在旁边伴舞，等到第一段副歌结束（`81.277s`，`L021–L023` / `SYNTH_013–SYNTH_014`）键盘音色再次出现而 Clawd 主体正忙于主线表演（`Business! / Dancing!`）时，就由旁边的**小 Clawd 分身负责弹奏键盘**！
   - **`L023`（`01:25.531 → 01:30.250`，*"Throwing a party... with you!"*，对应 `SYNTH_014`）**：产出更多小 Clawd 分身，分别操持键盘、鼓组、鼓掌、Bass 等声部，真正组成一支完整的 **Clawd 派对乐队**。
4. **环境中的节奏音色弹出小图标（`RhythmPopups`）**：
   - 在全员小 Clawd 乐队出场前，时间轴 `trk_claps_v1` 与 `trk_timbre_candidates_v1` 上标注的**鼓掌（单声拍手 & 双声快拍 `啪-啪`）、鼓组（开场快速双鼓点 & 每轮装饰鼓点）、镲片（`53.78s`）与 Bass 低频点**，先以统一像素风格的**小图标（拍手、交叉鼓槌小军鼓、金色镲片、青绿低音音箱）**在舞台两侧环境中随节奏不断轻巧弹出，既体现多声部节奏，又不干扰中央主角表演。

## 思考气泡段落（L013–L014）

2026-11-17 用户确认的脚本方向，尚待实现与试听、动态预览。详细内容写入两个事件的 Agent 备注，原时间点保持不变。

- L013（55.168–58.317s）：先冒出一个 `Thinking…` 气泡，再从四面八方逐渐加入许多小气泡，使用 Claude Code 终端状态行的等宽字体、英文状态词、省略号及小型字符轮转符号。词池包括 `Cooking…`、`Brewing…`、`Pondering…`、`Cogitating…`、`Ruminating…`，后段可加入 `Discombobulating…`。少数前景气泡可读，外围较小，保留角色脸部；眼神越来越忙，身体动作逐渐停住。
- L014（58.317–61.997s）：延续气泡，状态行突然一起停止更新，然后气泡逐个瘪掉消失，Clawd 短暂发愣。用停顿完成笑点，回到基础站姿，为副歌留出空间。具体气泡数量和动作切点由试看决定。

备用词池补充：`Baking…`、`Computing…`、`Crafting…`、`Mulling…`、`Noodling…`、`Synthesizing…`、`Marinating…`、`Moonwalking…`。按画面容量择用，不要求全部同时出现。词汇参考 [Claude Code 用户记录](https://github.com/anthropics/claude-code/issues/61352)，作为视觉素材使用。

此处以终端工作状态作为视觉隐喻，不展示实际工具执行或思维内容。该段的多个小气泡与 L007 的单个多语言大气泡分别服务于不同表演，沿用各自设计。
