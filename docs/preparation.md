## Agent 与用户如何配合

- 分析工具提供候选数据：拍点、起音、能量和声音变化等。
- Agent 编写并运行工具、解读数据和图表、提出段落草稿、实现时间线与画面；说明实际分析过什么、还不能确认什么。
- 用户通过播放与预览确认听感、视觉方向和表达重点，可直接说“这里提前一点”“这句结束后再出字”，无需先掌握剪辑术语。
- Skill 提供工作方法与 API 用法，不代替音乐分析模型，也不构成已经听辨音频的证据。

闭环：自动分析草稿 → 片段播放与人工校正 → 声音事件标记 → 镜头设计 → Remotion 预览 → 根据反馈调整。

拍点不等于每小节第一拍，波形峰值不等于剪辑点，频谱变化不等于确定的乐器或情绪。歌曲段落、重拍位置和歌词边界必须保留确认状态；不要求每一拍都切镜头。

## 数据与时间规则

以下为计划结构，实施时按需创建：

| 数据                                           | 计划位置                    | 规则                                                           |
| ---------------------------------------------- | --------------------------- | -------------------------------------------------------------- |
| 自动分析、参数、图表                           | `local/analysis/`           | 可重新生成，标注为候选                                         |
| 人工确认的音乐标记与修订                       | `local/annotations/`        | 与机器结果分开，重跑分析不得覆盖                               |
| 私人歌词与歌词时间标记                         | `local/annotations/lyrics/` | 不提交完整歌词                                                 |
| 需要在浏览器加载的分析派生数据、分轨或工作音频 | `public/private/`           | 保持私有，登记与原音源的关系                                   |
| 可公开的镜头安排与执行时间线                   | `src/timeline/`             | 先确认公开范围，再导入必要的确认数据，不携带完整歌词或私人记录 |
| 段落解释、创作目的、镜头状态                   | `docs/`                     | 引用稳定 ID，与代码保持一致                                    |

每批分析关联音源哈希、工具与参数，换音源时先检查标记是否仍然适用。分析结果保留秒数或采样位置及采样率，进入 Remotion 时统一加片头偏移并转换成整数帧；分析工具的特征帧与视频帧不是同一单位。FPS 变更时从原始时间重新计算，不反复换算已舍入的帧号。

标记使用稳定 ID，并记录来源（自动 / 人工）、状态（候选 / 已确认）、时间或区间、备注与关联镜头。重新分析产生新候选，不覆盖用户修订。保存后必须能重新载入；标注修改应能在后续工作中继续使用。

标注界面与画面预览使用统一的播放时间映射，明确音频零点和全片零点的关系；避免两个独立播放器各自计时造成漂移。先验证跳转、循环、暂停恢复及片头偏移，再扩展界面。

## 需要时再增加的能力

| 需求                   | 候选工具                         | 使用边界                                   |
| ---------------------- | -------------------------------- | ------------------------------------------ |
| 混音干扰鼓点或人声分析 | Demucs 等分轨模型                | 分离结果可能串音；最终配乐使用原音源       |
| 句级或逐字歌词动画     | 已核对文本 + WhisperX 等对齐工具 | 先做句级标注；语音模型用于歌唱时须逐段复核 |
| 旋律音高驱动画面       | Basic Pitch 等音符转录工具       | 作为音符候选，不假定能生成完整可靠的编曲谱 |
| 音量、频谱驱动视觉细节 | Remotion 音频工具                | 辅助连续动画，不替代镜头与段落设计         |

先完成时间点与段落标注，再判断是否需要乐谱。模型权重与分轨结果保存在本地；真正引入工具时再验证当前版本、Windows 兼容性、硬件需求和安装方式。
