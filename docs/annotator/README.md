# Annotator 当前界面设计

同步日期：2026-11-15。本文与图件按 `apps/annotator/` 当前实现整理，替代原 v5 提案中的过期样式、控件与候选状态说明。统一 `version: 1` 数据格式已经迁移（D010）；深色波形按 D011，状态图标按 D012。

- [净版主界面](design.svg)：当前布局及默认收起状态。
- [完整说明图](design.annotated.svg)：同一主界面与 18 个外围箭头说明框。
- [可编辑 Excalidraw](design.excalidraw)。

图中波形、事件、时间与计数均为合成示意，不是运行截图或歌曲分析结果，不包含真实歌词。图件用来说明布局与交互，不能代替实际播放、拖动、选色及保存验收。运行源码是实现依据；实际验证记录见 [推进计划](../roadmap.md)。

## 布局与层级

整体为顶部项目栏、播放与概览、波形及多轨区，下方为“时间轴 / 事件 / 事件编辑”三栏，底部为“Agent 协作”。

| 区域 | 当前表现 |
| --- | --- |
| 顶部项目栏 | 项目名、当前路径、保存状态；撤销、重做、导出 ASS/LRC、重载、保存。路径和状态为普通文字，保存为主要按钮。错误与未保存保留文字及强调色。 |
| 播放控制 | 播放/暂停、停止、循环、跳到选中标注、时间显示、拍点参考线、缩放和全曲范围。循环关闭时范围标为“待循环”。 |
| 时间轴导航 | 递归分组、搜索、折叠、显隐、锁定、新建及上下文菜单。 |
| 事件列表 | ID/文本、起点、终点与评论摘要；全部/含评论筛选及文本查找。另有“时间轴设置与评论”标签页。 |
| 事件编辑 | 所有语义共用一套编辑器，包含内容、时间微调、颜色、相邻边界、切分、500ms 试听及评论。未选事件时显示选择提示。 |
| Agent 协作 | 项目、分组、时间轴及事件评论汇总、定位、项目级评论、简报预览和复制。 |

分区用留白与分隔线组织，移除编辑区的多层底框。输入框和必要按钮保留边界；普通按钮与字段名不统一加粗。时间值、ID 和颜色代码保留等宽字体。内部字段名不进入普通操作文案，设置页内部 ID 仅留在悬停提示。

下方三栏分隔线可拖动，Tracker 高度可调整。当前未提供倍速、吸附、自动分析候选导航节点、按作者筛选、窄屏自动折叠为抽屉或布局持久化；不再将这些提案功能绘为现有控件。三栏双击复位也不是当前已实现行为。

## 配色与波形

| 用途 | 色值 | 使用方式 |
| --- | --- | --- |
| 页面底 | `#f3f5f5` | 面板之间的背景 |
| 主面板 | `#ffffff` | 正文、列表和输入框 |
| 辅助面板 | `#f8fafa` | 工具栏与辅助区域 |
| 选中底 | `#e7f2f2` | 当前轨道或事件 |
| 强调色 | `#166b75` | 主要操作、选中描边 |
| 正文 / 辅助文字 | `#263238` / `#637079` | 主次信息 |
| 边框 | `#cbd2d6` | 分隔线与必要控件边界 |
| 主波形底 | `#0c1017` | D011 指定的旧版深色波形 |
| 波形 / 播放进度 | `#334155` / `#0284c7` | WaveSurfer 实际配色 |
| 波形游标 | `#f43f5e` | WaveSurfer 当前时间位置 |
| 刻度背景 | `#131924` | 波形下方时间尺 |
| 轨道播放头 / 警示 | `#b44e32` | 轨道播放头及必要警示文字 |

原提案主波形 `#b8cdd2 / #355f69` 已由 D011 替换，不能再用作当前主波形色。正文完整不透明；区间局部覆盖可半透明，避免对整块面板降透明度。颜色不独立承担作者、锁定或错误含义。

主波形使用 WaveSurfer + Regions + Timeline，138px 波形加 24px 刻度，`normalize: false`。输入真实分析包络作为预计算 peaks；缺失时提示，不用示意波形补位。选中与相邻区间显示半透明区域，其余事件显示起点。App 音频元素是唯一播放时钟，WaveSurfer 同步显示，避免两个播放器独立计时。

### 可调轨道名称栏

- 默认及最小宽度为 **64px**，扣除色标、内边距后保留至少两个全角字符的名称空间；长名称显示为“歌…”，悬停查看完整路径。
- 名称栏右边界可拖动，最大 360px，并为波形预留空间。双击该边界恢复最窄。
- 聚焦边界后，左右方向键调整 8px，Shift+方向键调整 1px；Home/End 到最小/最大宽度。
- 波形和各轨道共用名称栏宽度，并补偿轨道纵向滚动条占位；ResizeObserver 更新波形缩放与可见起点。
- 锁定轨道的色标位置改为锁图标，避免挤占窄栏名称。宽度仅为当前页面状态，不进入标注 JSON。

## 状态、菜单与提示

时间轴树使用眼睛和锁图标，来源及许可见 [素材 A002](../assets.md)。可见/已锁定显示正常图标，隐藏/未锁定使用 `/` 斜杠；图标反映有效继承状态，保留悬停提示、可访问名称、按下状态与键盘聚焦入口。分组锁作用于下级，子轨道不能绕过继承锁。

桌面节点的“···”在悬停、行内聚焦或选中时显示；触屏始终可见，并预留原位置避免行内容跳动。导航与列表的长说明收进可键盘展开的“操作提示”。评论数量与作者角色使用普通辅助文字，锁定提醒使用中性底和“已锁定”说明。

右键事件列表或点击等价菜单可新建点/区间、切分及删除；切分要求单个区间且播放头位于内部。分组菜单在组内新建，轨道菜单在同级新建，空白处新建根节点。非空分组删除明确提示子树影响数量，锁定节点不能绕过写入校验；删除支持撤销。

## 事件编辑与颜色

所有标注共用 `TimelineEvent` 和一套事件编辑器，不按歌词、节奏、结构或自定义语义切换。点事件没有终点；区间使用 `[startSec, endSec)`。时间数值输入、微调与拖动边界更新同一对象。

相邻边界默认独立，保留真实人声留白。“联动公共边界”和主动“设为紧邻”是不同动作，不能按短间隙自动合并。会话绑定不进入业务 JSON，只保存操作后的起止时间。

试听窗口默认 500ms，A/S/R/D/F 分别对应起点前、起点后、整段、终点前、终点后；输入文字时不拦截。“下一条标注”切换选择，不写入确认状态。

事件颜色解析为 `event.color → track.color → #166b75`。事件和时间轴颜色设置均默认折叠，收起只显示色样与来源；展开后提供原生选色、精确色值和预设色。预设色先预览，确认作为一次可撤销更新，取消不修改已保存颜色。确认/取消位于折叠区外，折叠不会隐藏未完成草稿的操作。

事件“跟随时间轴”移除事件覆盖色；时间轴“恢复默认”移除时间轴颜色。只保存可选 `#RRGGBB`，不保存派生填充色或透明度。移动事件时，继承色跟随目标轨道，显式覆盖色保留；切分继承颜色。图件主界面展示默认收起态，展开行为在箭头说明和本文中记录。

## 存储与协作

| 对象 | 必需字段 | 可选字段 |
| --- | --- | --- |
| Project | version、name、nodes | audio、comments |
| Group | kind: group、id、name、children | comments |
| Timeline | kind: timeline、id、name、items | color、comments |
| Event | id、startSec、text | endSec、color、comments |
| Comment | role: human 或 agent、text | 无 |

`version: 1` 已用于当前主时间线。Group.children 可递归包含 Group 或 Timeline，数组顺序即展示顺序；稳定 ID 用于定位，选择使用 trackId + eventId。`audio` 为相对路径，音频秒数为编辑坐标，不在事件中重复保存帧号与采样位置。

项目、分组、时间轴和事件使用相同 `comments: { role, text }[]`。顺序即讨论顺序，备注、脚本想法与回复也放入该数组；不根据最后作者猜测任务完成状态。列表摘要和协作简报由主 JSON 派生，不另存任务状态或第二份事实来源，协作栏不会自动调用模型。

hash、revision、分析清单、播放位置、FPS、循环、显隐、锁定、面板宽度、草稿及 boundary_links 不进入这份业务 JSON。分析产物和音源继续按项目私有目录约定管理，重跑分析不能覆盖人工标注。

## 维护与验证

运行 `node tools/design/review-annotator-design.mjs`，同步生成 Excalidraw、净版 SVG 和完整说明 SVG。当前界面构图在 `tools/design/current-annotator-design.mjs`；主生成入口负责快照、形状、箭头及导出。重建前将已有图件按内容哈希备份到 `local/design/`，保留不属于生成元素的手工新增对象。手工意见需同步到构图脚本，避免下一次生成与图件分离。

`schema.types.ts` 仅描述当前持久化规格，不被运行程序导入；界面与编辑会话类型以运行源码为准，已移除旧提案中的倍速、吸附等临时类型。

已记录的验证包括 lint、仓库检查、前端构建及部分内存隔离检查。当前样式仍需实际浏览器验收：名称栏拖动与省略、调整后的波形/轨道定位、键盘与触屏、颜色弹窗及预览确认/取消。图件渲染检查不等同于这些交互已通过。
