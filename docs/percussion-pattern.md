前奏约0.53–18.47秒的四个连续窗口内，强打击瞬态的轮内位置重复。约4.4859秒为一个对照窗口，按已有约107 BPM候选网格分成32个约0.1402秒的格点。这个分组用于比较，不确认拍号或小节第一拍。

| 轮内格点 | 相对秒数约 | 观察/解释 |
|---|---:|---|
| 0 / 8 / 16 / 24 | 0 / 1.121 / 2.243 / 3.364 | 主要“嗒”的打击瞬态候选，与常规鼓掌交错 |
| 4 / 12 / 20 / 28 | 0.561 / 1.682 / 2.804 / 3.925 | 既有常规鼓掌的位置 |
| 26 | 3.645 | 每轮都有较强打击瞬态；部分轮次又有人工确认的额外鼓掌第一声 |

前奏明确的额外鼓掌第一声为4.173s和13.145s，相隔约8.972s（两个对照窗口），都接近第26格。第26格强瞬态在四轮的检测位置为4.1805、8.6703、13.1501、17.6404s附近。常规第二声继续落在第28格，距第26格约0.280s。因此，一个可检验的解释是：**同一时间网格上的交错落点，加上隔轮出现的额外鼓掌，使局部出现靠近/叠加**；当前证据不要求假设两种不同速度不断漂移后相遇。

分别对这四轮的两组主要起音位置作线性拟合，间隔约1.121305s与1.121613s，最大拟合残差约3.3ms与6.3ms；这点差别小于混音瞬态定位的不确定性，不能当作两种独立速度的证据。
