# 素材清单

每个使用的素材分配稳定 ID；无法确认可以公开的文件默认放私有目录。登记表不包含购买凭证、私人下载地址或完整歌词。

| ID   | 素材                                 | 本地路径                           | 来源 / 依据                              | 可提交 GitHub | 用途    | 状态                         |
| ---- | ------------------------------------ | ---------------------------------- | ---------------------------------------- | ------------- | ------- | ---------------------------- |
| A001 | Kero Kero Bonito — Try Me，FLAC 音源 | `public/private/audio/try-me.flac` | 用户提供，用户说明已购买正版；凭证不入库 | 否            | MV 音轨 | 本地私有归档，未转码，待接入 |

| 位置                    | 用途                         | Git                  |
| ----------------------- | ---------------------------- | -------------------- |
| `public/assets/images/` | 原创或可再分发图片、纹理     | 登记来源后提交       |
| `public/assets/fonts/`  | 可再分发字体及对应许可文件   | 登记许可后提交       |
| `public/assets/video/`  | 可再分发视频素材             | 提交前评估体积       |
| `public/assets/audio/`  | 自制或可再分发音效，按需启用 | 默认忽略，逐文件放行 |
| `public/private/`       | 不可公开但运行时要加载的素材 | 整个目录忽略         |
| `local/references/`     | 视觉参考原件                 | 整个目录忽略         |
| `local/source/`         | 不参与运行时加载的源工程     | 整个目录忽略         |
| `local/notes/`          | 私人笔记、购买记录           | 整个目录忽略         |
| `out/`                  | 视频、静帧等生成产物         | 整个目录忽略         |

`public/` 是 Remotion 运行时资源目录，不表示内容可以公开；`private` 只提供 Git 隔离。使用 `staticFile("private/audio/try-me.flac")` 等路径引用，参见 [官方资源说明](https://www.remotion.dev/docs/assets)。

转码时保留原 FLAC，派生文件放同一私有目录并登记参数、裁剪情况和时间零点变化。第一次接入时验证 FLAC 预览与渲染兼容性，不提前假定已经验证。

## 公开边界

仓库只公开代码、原创文档、允许再分发的素材与必要署名。歌曲、转码版本、含歌曲的成片及含私有资源的 bundle 不随仓库、Release、Actions artifacts 或 Pages 发布。Git LFS 也会上传文件，不用于存放这首歌。

`.gitignore` 不影响已经跟踪的文件。若发生误提交，先确认暂存区、历史和远端范围，再决定清理方式；增加忽略规则不能移除已有记录。
